BCP Clock

This page installs the BCP Clock firmware on an Ulanzi TC001 pixel clock, directly from your browser. Nothing else needs to be installed.

You need

  • A computer with Google Chrome or Microsoft Edge (Windows, macOS, Linux or ChromeOS). Phones, tablets, Safari and Firefox do not work.
  • A USB-C data cable. Some cables only charge; if the clock is not found, try another cable.
Your browser cannot install firmware. Open this page in Google Chrome or Microsoft Edge on a computer. The page must be opened over HTTPS.

Steps

  1. Connect the clock to the computer with the USB-C cable, directly, not through a USB hub.
  2. Click Install above. The browser lists the serial ports: choose the one that appeared when you plugged in the clock (usually named USB Serial, CH340 or usbserial) and click Connect.
  3. Confirm the installation. On the first installation keep Erase device ticked; when updating BCP Clock, untick it to keep your WiFi networks and settings.
  4. Wait about two minutes until the installation finishes. Do not unplug the clock meanwhile. The clock may beep while it is being installed; that is normal.
  5. The clock restarts with BCP Clock. Continue with the first setup: connect the clock to your WiFi and enter the event.

No port appears?

  • Try another USB-C cable or another USB port on the computer.
  • On Windows, install the CH340 USB driver and reload this page.

Installing replaces the original Ulanzi firmware. To be able to go back to it, back it up first (how). More information, source code and all releases: github.com/honzaskypala/bcp-clock.
